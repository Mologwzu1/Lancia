# 面向 CyberRT 的自动驾驶调度可观测平台的设计与实现
## 一、任务、目的与要求：
### 1、任务目的

本课题拟设计并实现一款基于CyberRT的自动驾驶调度可观测平台。平台围绕自动驾驶关注的关键指标建立指标体系，将端到端时延、调度抖动等指标分解为基础事件与字段，并通过对CyberRT的埋点、插桩等相关改造获取调度与通信过程中的关键数据，形成统一的时间线表达。
在此基础上，平台实现两类核心输出：一是面向指标监控与评估的统计报表与分析结果；二是面向问题复盘与定位的Perfetto trace生成与可视化回放能力，能够在同一时间线上展示节点执行区间、消息传递链路及关键指标变化，辅助中间件研发人员并兼顾测试人员与监控平台开发人员基于录制数据快速发现异常、缩短根因归因路径，从而提升系统底座实时性问题的定位效率与优化闭环能力。除此之外，实验测试多场景（如正常、高负载、异常情况）下的链路时延分布。

### 2、任务内容

为了解决以上技术难题，本平台围绕端到端时延、调度抖动等关键指标，完成指标定义，将指标分解映射为可采集、可计算、可关联的事件与字段，形成指标体系；增强关键消息的发布节点，通过埋点、插桩等方式采集调度与通信等关键数据，依此支持全面的调度可观测分析。基于采集数据生成指标报表，同时根据用户配置的自动驾驶链路（如感知→规划→控制），平台应支持使用可观测中间件重建因果链；在此基础上，利用Perfetto实现链路传递、模块调度和延迟情况的可视化。另外，展示在多场景实验（如正常、高负载、异常情况）下链路的时延分布，为研发人员你的性能优化工作提供参照。
